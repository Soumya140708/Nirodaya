# Nirodaya — Emergency Assistance Platform (Work in Progress)

Nirodaya is a medical emergency assistance platform concept that aims to help people reach emergency medical support and check essential medical supplies faster.

> **Status: Work in progress.** Four pages of the frontend are built using sample data. There is no backend, GPS tracking, ambulance booking or hospital alert system yet.

The concept was suggested by a friend. The website design and frontend development are by Soumya.

## Concept

Delays in finding an ambulance, a hospital or a critical supply such as oxygen or insulin can be dangerous. Nirodaya aims to bring these into one simple dashboard.

## Pages Built So Far

| Page | File | What it does |
|------|------|--------------|
| Home | `index.html` | Introduction, service shortcuts and demo network overview |
| Live Response Map | `map_p2.html` | Illustrative map with filters for ambulances, hospitals, pharmacies, clinics and blood banks; click a marker to see its details |
| Medical Supplies | `supplies_p3.html` | Sample supply cards (blood, oxygen, medication, PPE, equipment) with category filters, search and stock bars |
| Request Aid | `request_p4.html` | Form that prepares a demo request; nothing is sent to any service |

## Technologies Used

- HTML5
- CSS3 (Grid, Flexbox, responsive layout)
- JavaScript (filters, search, form interaction)

## What Is Not Implemented Yet

- Finding the nearest or fastest ambulance
- Real ambulance booking
- Emergency alerts to hospitals (for example, for a heart attack)
- Live GPS or a real map
- Real supply data, price comparison and delivery or booking options
- Backend and database

All locations, quantities and statuses on the site are fictional sample data. The Emergency SOS button only shows a message. **For a real emergency in India, call 112.**
